# 프로젝트 개발 및 커뮤니케이션 규칙 (Quotations Generator)

## 인쇄방식 타겟팅 머리말 규칙
사용자가 작업 요청 시 아래 태그를 프롬프트 머리말에 포함할 경우, 에이전트는 타 인쇄방식 모듈에 영향을 주지 않도록 해당 태그 범위 내의 독립된 코드/모듈만 엄격히 격리하여 수정 및 구현해야 합니다.

- **`[경인쇄]`** 또는 **`[경인쇄 전용]`**: 경인쇄 계산 로직(`calculateKyung`), 경인쇄 엑셀 템플릿 처리(`processKyungExcel`), 경인쇄 전용 UI 폼 영역만 독립 수정
- **`[옵셋]`** 또는 **`[옵셋 전용]`**: 옵셋 계산 로직(`calculateOffset`), 옵셋 엑셀 템플릿 처리(`processOffsetExcel`), 옵셋 전용 UI 폼 영역만 독립 수정
- **`[디지털]`** 또는 **`[디지털 전용]`**: 디지털 계산 로직(`calculateDigital`), 디지털 엑셀 템플릿 처리(`processDigitalExcel`), 디지털 전용 UI 폼 영역만 독립 수정
- **`[공통]`**: 공통 레이아웃, 헤더/푸터 및 시스템 전반 공통 모듈 작업
